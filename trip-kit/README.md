# 旅遊行程公版（trip-kit）

以 2026 大阪行程表為原型整理出的公版。所有旅程共用同一套外觀（與「家的旅程」相同的 みのわ 風格），
改 `trip.css` 就會讓每一趟一起換樣式。

## 檔案

| 檔案 | 用途 |
|---|---|
| `trip.css` | 四頁共用的配色與版面質感（各頁自己的 `<style>` 只放骨架） |
| `trip.js` | 深色標籤自動轉淺色、頁尾留白 |
| `../trip-home.js` | 左下「家的旅程」返回鈕（PWA 沒有返回鍵） |
| `template/` | 公版：行程（index）、地圖（map）、美食（food）、刷卡（card） |

## 開新的一趟

1. 把 `template/` 整個複製到 repo 根目錄，改名成 `<地點><年>-trip/`（例：`nagoya2027-trip/`）
2. **index.html**：改最上面那段 `const TRIP={...}`
   - `id` 每趟要不同（手機裡的打勾與刷卡紀錄用它分開存）
   - `days` 每天日期，順序對應 D1、D2…；`dep`／`ret` 出發與回到台灣的時間；`tz` 當地時差
   - 內容照範例：`出發前準備` 一個 `.card`，每天一個 `.day-block`，每一項是一個 `.item`
   - 項目可加：`🚇 交通`（`.transit`）、`🔁 備案`（`.altbox`）、`💳 刷卡`（`.payl`，`data-day` 對應 D 幾）
   - 刷卡卡片清單在 script 裡的 `CARDS`、`CAP_NT`，依這趟要用的卡修改
3. **map.html**：改 `HOTEL`、`AIRPORT`、`DAYS`（座標可在 Google 地圖長按複製）
4. **food.html**、**card.html**：照範例填
5. 在根目錄 `trips.json` 加一筆，「家的旅程 → 旅遊」的日曆與紀錄就會出現這趟

> 注意：行程項目的「順序」就是打勾紀錄的對照；出發後要增刪項目，打勾狀態可能會錯位，盡量在出發前定稿。
