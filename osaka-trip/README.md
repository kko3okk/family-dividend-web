## 使用方式

開啟 `index.html` 即可。點擊方框可打勾，**打勾狀態會自動保存在瀏覽器**，重新整理不會消失。

## 放到 GitHub Pages（手機隨時開）

1. 在 GitHub 建一個新 repository（例如 `osaka-trip`），設為 Public
2. 上傳 `index.html` 和 `README.md`
3. 進入 repo 的 **Settings → Pages**
4. Source 選 **Deploy from a branch**，Branch 選 **main** / 資料夾選 **/ (root)**，按 Save
5. 等 1–2 分鐘，網址會是：`https://<你的帳號>.github.io/osaka-trip/`
6. 手機開啟後可「加入主畫面」，像 App 一樣使用

> 注意：Public repo 的內容任何人都看得到。若不想公開，改用 Private repo（Pages 需付費方案），或直接把 `index.html` 存在手機/雲端硬碟開啟。
